Skill check: where should it appear?

Example: Fordham "Web Strategist" posting. These skills appear in the posting but not in your master resume. Click the layout you prefer.

A

Pause mid-run (card on the job page)

Run starts right away. After the job description is parsed (~10s), it pauses and shows this card. Same pattern as the existing "Some bullets need your call" card.

B

Check before the run (step after pasting the job description)

Click "Check skills" first. The parse runs, the list appears, you tick, then press "Tailor resume". The run never pauses after that.

A: pause mid-run

  • One click to start, same as today
  • Shows why each skill is "close" to your experience
  • Fits the existing pause/resume system
  • But you have to come back once the run reaches that point

B: before the run

  • Answer once, then walk away; run never stops
  • Faster to scan (chips)
  • Adds a click before every run
  • Fewer details per skill
